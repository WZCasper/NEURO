## Структура репозитория

```
index.html              — главная страница
404.html                — страница «не найдено»
apps/                   — страница каждой программы
assets/css/style.css    — стили
assets/js/main.js       — навигация, 3D-анимация нейросети на canvas, наклон карточек
assets/js/downloads.js  — подтягивает актуальный релиз с GitHub Releases для каждой программы
assets/img/             — favicon и графика
.github/workflows/      — автодеплой на GitHub Pages при пуше в main
```

Сайт полностью статический, без сборки — открыть `index.html` можно напрямую в браузере.

## Как работают кнопки «Скачать»

Кнопка загрузки на каждой странице обращается к `https://api.github.com/repos/<repo>/releases/latest` того репозитория, где лежит конкретная программа, и подставляет прямую ссылку на .exe/.zip из последнего релиза. Отдельно поддерживать ссылки на сайте не нужно: как только в репозитории программы публикуется новый релиз, кнопка на сайте автоматически предложит скачать именно его.

Чтобы кнопка сразу нашла установщик, а не архив с исходниками, называйте exe-файл в релизе так, чтобы в имени было слово `setup` или расширение `.exe`/`.msi` — иначе программа предложит первый файл из списка вложений релиза.

Если у репозитория ещё нет ни одного релиза, кнопка показывает статус «Скоро».

Рядом с кнопкой скачивания на странице каждой программы есть блок «История версий» — он читает `https://api.github.com/repos/<repo>/releases` и сам показывает несколько последних версий с датами.

## Как обновляется описание программы

На детальной странице каждой программы есть карточка «О проекте» (`<p class="readme-desc" data-repo="владелец/репозиторий">`). Она читает `README.md` репозитория программы (`raw.githubusercontent.com/<repo>/main/README.md`, с запасным вариантом на ветку `master`) и сама подставляет первый абзац после заголовка — без правки HTML на сайте. Обновили README на GitHub — текст на сайте обновится сам при следующем визите (кэшируется в рамках вкладки браузера на 10 минут).

Если во вступительном абзаце README нет текста, пригодного для показа (абзаца нет вообще, он не на русском языке, или сразу за заголовком идёт список/таблица/цитата), скрипт ничего не подставляет:
- если в `.readme-desc` в HTML изначально ничего не написано — карточка «О проекте» на странице просто скрывается;
- если там заранее вписан резервный текст (как у NeuroBoost, где README на английском) — остаётся он.

Главный рекламный текст программы (`.lede` вверху страницы и `.desc` на карточке на главной) из README **не** подтягивается и остаётся полностью ручным — это сделано осознанно, чтобы сухой технический текст из README не заменял продуманные формулировки на сайте.

## Обновление контента

- Текст и список функций каждой программы — в соответствующем файле `apps/*.html`.
- Цвет-акцент каждой программы задаётся атрибутом `data-accent` (`violet`, `cyan`, `magenta`, `amber`, `teal`, `blue`) на карточке/шапке страницы — все шесть вариантов уже заняты, для новой программы переиспользуйте один из них так, чтобы он не стоял на главной странице в сетке рядом с карточкой того же цвета.
- Чтобы добавить новую программу: скопировать один из файлов в `apps/`, обновить текст, иконку, `data-repo` у кнопки скачивания (`.js-download`), истории версий (`.changelog-list`) и блока «О проекте» (`.readme-desc`), добавить карточку на `index.html`, ссылку в футере на всех страницах и строку в `sitemap.xml`.

## Скриншоты программы на странице

На детальной странице каждой программы под шапкой может быть витрина скриншотов — 3D-карточка с лёгким наклоном, которая выравнивается при наведении или фокусе, и каруселью со стрелками/точками, если скриншотов больше одного (`assets/js/screens.js`).

Чтобы добавить скриншоты новой программе:
1. Сохранить изображения в `assets/img/screenshots/` в формате `.webp` (PNG из Windows сжимается в WebP примерно в 5–7 раз без видимой потери качества для UI-скриншотов; конвертировать можно через Pillow: `im.save("file.webp", "WEBP", quality=82, method=6)`).
2. На странице программы между `</header>` и `<div class="detail-grid">` вставить блок `<section class="screens">…</section>` — проще всего скопировать его целиком с готовой страницы (`apps/neuroboost.html` для нескольких скриншотов, `apps/neurovox.html` для одного) и заменить пути к картинкам, `alt`-подписи и `width`/`height`.
3. Если скриншот один — стрелки и точки-переключатели скрипт скроет сам, трогать разметку для этого не нужно.
